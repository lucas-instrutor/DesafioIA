# DesafioIA
O Gemini Notebook será minha ferramenta para construir um segundo cérebro com IA. Neste desafio, meu foco é aprender neurociência com o neurocientista brasileiro e referência no assunto, Miguel Nicolelis.

Objetivo: Dominar a neurociência, desde os conceitos fundamentais até tópicos avançados, utilizando exclusivamente como base a obra e os artigos científicos de Miguel Nicolelis. Nenhuma outra fonte ou autor deve ser considerado.

Orientações de Fontes: Apenas conteúdos em texto, artigos e vídeos de autoria do Nicolelis podem ser utilizados. Caso a informação venha de um podcast, insira a seguinte formatação de citação: [Segundo o Podcast "Nome do Podcast", ...]
